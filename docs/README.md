# Gurukul user guides

Written for the people who use Gurukul, not the people who build it (that is `CONTRIBUTING.md` and
`.plan/`). Every guide describes what is built today.

- [Learner guide](learner.md): sign in, take a course, pass a Pariksha, get and share a certificate.
- [Kulapati guide](kulapati.md): assign courses, follow progress, manage roles, send reminders.
- [Acharya guide](acharya.md): build, preview and publish a course in Vyasa Studio.
- [Setting up a new environment](operations.md): first sign-in, the first Kulapati, backups.
