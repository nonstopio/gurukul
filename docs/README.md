# Gurukul user guides

Written for the people who use Gurukul, not the people who build it (that is `CONTRIBUTING.md` and
`.plan/`). Every guide describes what is built today.

- [Learner guide](learner.md): sign in, take a course, pass a Quiz, get and share a certificate.
- [Admin guide](admin.md): assign courses, follow progress, manage roles, send reminders.
- [Educator guide](educator.md): build, preview and publish a course in Studio.
- [Setting up a new environment](operations.md): first sign-in, the first Admin, backups.
