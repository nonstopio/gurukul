# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/nonstopio/gurukul/security/advisories/new),
not in a public issue. We aim to acknowledge reports within three working days.

In scope: the code in this repository, `firestore.rules`, and the deployed app
at the project's Firebase Hosting domain. Out of scope: social engineering,
denial of service, and findings that require a compromised Google account.
